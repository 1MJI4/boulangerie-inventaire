## Constat principal

L'application n'a **aucune authentification** : pas de `middleware.ts` ni de `proxy.ts`. Le
« profil manager » n'existe que dans le navigateur (`src/lib/profils.ts`,
`src/components/GardienProfil.tsx`, localStorage), le serveur ne le connaît pas.

Un seul secret partagé protège quelques écritures : `CODE_GESTION`, **4 chiffres**, identique
à l'ancien code écrit en dur, présent dans l'historique git poussé sur `origin/main`.

## 2. Failles

### Critique
- **C1 — Code gérant public de fait.** `CODE_GESTION` = ancien code en dur, présent dans les
  commits `72bb1a9`, `c21446d`, `8f24759` et dans `SETUP-SUPABASE.md:23`.
  → Quiconque a vu le dépôt peut faire `PATCH /api/tarifs` et changer un prix.
- **C2 — Données clients lisibles sans authentification** (`commandes/route.ts:34-78`).
  → Une boucle sur `?id=1…N` aspire tous les noms et téléphones.
- **C3 — Commandes modifiables sans authentification** (`commandes/route.ts:111-206`, `210-397`).
  → Annuler les commandes du week-end, ou ramener un total à 1 centime (l.148, 330-331).
- **C4 — Inventaires écrasables sans authentification** (`inventaires/route.ts:119`).
- **C5 — Code à 4 chiffres forçable.** Seule `gestion/route.ts:31` temporise (contournable en
  parallèle) ; `tarifs:15-18`, `produits:12-15`, `gateaux:14-17`, `reorganiser:12` comparent
  sans délai, sans limite de débit, sans comparaison à durée constante.

### Haute
- **H1 — Injection de travaux d'impression** (`impression/route.ts:19-74`).
- **H2 — Clé CloudPRNT dans l'URL** (`cloudprnt/[cle]/route.ts:27-33`) : journaux Netlify,
  `console.log` dans `scripts/imprimante-simulee.mjs:36`, comparaison non constante (l.32),
  pas de rotation.
- **H3 — Identité déclarée par le client** (`commandes/route.ts:117` `vendeur`, `:214` `auteur`).
- **H4 — Prix créés librement** (`tarifs/route.ts:72-101`, `commandes/route.ts:102`).
- **H5 — Aucune politique RLS** ni `GRANT`/`REVOKE` (`setup-supabase.sql`, `prisma/migrations/*`).

### Moyenne
- **M1** — Rôles appliqués seulement dans le navigateur (`profils.ts`, `GardienProfil.tsx`, `parcours.ts:33-42`).
- **M2** — Page de dev `src/app/test-api/page.tsx` déployée (gestion produits, suppression forcée).
- **M3** — Erreurs Prisma journalisées brutes (`commandes/route.ts:80, 203, 394`…), peuvent contenir nom/téléphone.
- **M4** — Réponses d'erreur décrivant l'infrastructure (`erreurBase.ts:21-73` ; `gateaux:22-24`, `produits:20-22`, `tarifs:23-25`). Contraire aussi à la LOI 9.
- **M5** — Aucune validation par schéma (ex. `inventaires/route.ts:166-171`, `produits` POST sans longueur max).
- **M6** — Aucun en-tête de sécurité (`next.config.ts`, `netlify.toml:24-27`).
- **M7** — PUT de maintenance des commandes déclenchable par tous (`commandes/route.ts:406`).
